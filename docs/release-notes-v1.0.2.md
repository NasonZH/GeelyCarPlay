# CarPlay v1.0.2

发布日期：2026-11-25

## 重要变更

- **应用更名为 CarPlay**，包名改为 `com.carplay`；与旧版 `com.geely.carplay.ui` 不互通，无法覆盖安装。
- 旧版可先卸载再安装新版，或与新版共存；旧包的设置、配对和 MFi 资产不会迁移。
- 热点信息迁移到设置页，连接页移除热点面板，首页刷新逻辑简化。
- 设备选择页优先显示系统蓝牙别名，避免显示厂商缓存名。

## 安装包

- 文件：`CarPlay-v1.0.2.apk`
- 包名：`com.carplay`（应用名 CarPlay）
- 大小：7,250,173 字节
- SHA-256：`ECF068701499F7AD5C06971F109300AC12F67696D992E38E5F2FCC277AD97347`
- 要求：Android 4.3+（minSdk 18）
- 升级：包名变更属于不兼容更新，不能覆盖旧版
- 说明：仓库不包含 Apple MFi 认证资产，构建需自备 `app/src/main/assets/offline-mfi/`；Release 安装包包含本机认证资产

## 与 v1.0.1 相同的能力

- 视频帧缓冲池化，车机 GC 约 0.17–0.22 次/秒。
- 5GHz 信道 149 + 802.11n + WMM（车机系统脚本，不在仓库）。
- 通话接通时自动把投屏页拉回前台。
- 按蓝牙实际连接判断设备在线，连接页离线设备置灰且不可点击。
- 日志限流、iAP2 隧道缓冲重写、音频缺口 `gaps/gapFrames` 统计。

## 车机系统侧改动（不在仓库）

- `/system/bin/hostapd` 包装脚本：2.4G 信道/WMM、5G 信道 149 + 802.11n；备份、验证与回滚命令见 `docs/troubleshooting.md`。
- 换车、OTA 或恢复出厂后会丢失，需要重新应用。

## 已知问题

- 导航 Opus 仍有偶发 1–2 包缺口，尚未做缺口隐藏。
- 通话自动拉回投屏待实机验收。
- USB/H52 真车音频、Siri、车载麦克风未验收。
