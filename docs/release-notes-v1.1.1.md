# CarPlay v1.1.1

发布日期：2026-11-28

## 亮点

- **原生 ChaCha20-Poly1305 解密**：视频大帧解密尖峰从 300–748ms 降到 100ms 以内，画面更跟手；原生库不可用时自动回退 BouncyCastle。
- **通话界面自动缩小**：通话接通后自动点车机通话界面的“缩小”，退出 CarPlay 通话页，并回到通话前的页面（首页/连接页/设置/投屏页）。
- **音量键修复**：导航轨道不再提前占用音频焦点，播放音乐时音量键调节媒体音量。
- **断开播放修复**：断开连接前先暂停手机音乐，避免断开后由车机蓝牙继续播放。
- **启动页热点准备**：启动页先关闭 Wi-Fi 客户端再启动热点，解决无线与热点互斥。

## 新增设置

- 连接设置 → **自动缩小车机通话**（默认开启）。

- 文件：`CarPlay-v1.1.1.apk`
- 包名：`com.carplay`（应用名 CarPlay）

## 验证情况

- 原生解密自检通过，实机视频处理尖峰 <100ms；
- 通话自动缩小、来电接通后触发、回到通话前页面均已在车机验证；
- 音量键与断开后音乐停止已在车机验证。
