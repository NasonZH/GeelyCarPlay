# CarPlay v1.1.0

发布日期：2026-11-26

## 更新内容

- **首页直接连接**：无线和 USB 连接入口直接放在首页，无线连接支持多台当前蓝牙在线手机的选择，USB 连接独立检查本地 VPN 授权。
- **连接日志页**：集中展示连接过程，可取消或重新连接；成功后自动进入 CarPlay，从投屏返回日志页不会重复跳转。
- **首页状态与布局**：每 2 秒检测热点和蓝牙状态，热点胶囊仅用图标颜色表示状态；在线设备名称以绿色单行展示，左侧内容居中，连接按钮统一为同色纯文字样式。
- **连接后设备显示**：隐藏蓝牙设备区，保留绿色的“正在投屏”设备名称。
- **媒体按键转发**：补齐前台投屏页的上一首、下一首和播放/暂停入口；长按重复和松开事件不重复发送，未识别或无法入队的按键继续交给系统。
- **刷新与取消保护**：减少原厂蓝牙读取失败时的重复等待；取消连接准备后忽略旧回调，返回首页不重复弹出自动连接日志页。

## 安装包

- 大小：7,238,555 字节
- SHA-256：`d4e49ad9e85ffce4215b372a78687ac4aa3a5b323043000d691cf5f2b5771646`
- 版本：`1.1.0`（versionCode 4）
- 包名：`com.carplay`（应用名 CarPlay）
- 要求：Android 4.3+（minSdk 18）
- 升级：沿用 v1.0.2 包名，签名一致时可覆盖安装；旧版 `com.geely.carplay.ui` 不能覆盖升级，设置及配对信息不会迁移。
- 说明：仓库不包含 Apple MFi 认证资产，源码构建需自备；本次发布安装包沿用本机认证资产。

## 验证与已知限制

- 应用源码、测试源码编译和 APK 打包成功；未执行单元测试、启动应用或实机连接测试。
- 本轮首页、连接日志页和自动进入行为仍待实机验收。
- **实车媒体按键切歌效果待验收**：当前支持送达前台投屏页的标准按键事件，未新增后台媒体广播接收或厂商按键适配。日志中的入队成功不代表 iPhone 已执行。
- USB/H52 真车音频、Siri、车载麦克风和通话自动拉回投屏仍待专项验收。
- 导航 Opus 偶发缺口尚未做缺口隐藏。
- 5GHz 信道、WMM 与 802.11n 的车机系统脚本配置不在仓库内，换车或 OTA 后需按排障手册重新核对。
