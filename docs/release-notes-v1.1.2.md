# CarPlay v1.1.2

发布日期：2026-11-28

## 新增

- **导航时媒体音量设置**：设置 → 音频 → “导航时媒体音量”，可拖动调节 **10–100%**，默认 **70%**；
- 导航播报期间媒体按该比例保留音量，拖动时实时显示百分比；
- 70% 表示保留 70% 的媒体振幅（约 −3 dB）。

## 说明

- 修改后重新连接 CarPlay 生效（与其它音频设置一致）；
- 该比例作用于媒体轨道音量，不影响车机音量旋钮的档位。

- 文件：`CarPlay-v1.1.2.apk`
- 包名：`com.carplay`（应用名 CarPlay）

- SHA-256：`9448972E8BCAD8C3B2277445B14881FF14E4E1D8523CD4548042187903BA455C`

- 升级：与 v1.1.1 同签名，可直接覆盖安装

## v1.1.1 已包含

- 原生 ChaCha20-Poly1305 解密；
- 通话接通后自动缩小车机通话界面并回到通话前页面；
- 来电响铃阶段不缩小；
- 音量键回到媒体流；
- 断开连接前暂停手机音乐；
- 启动页先关无线再启动热点。
